This is a Maven project implementing a set of ImageJ 1.x plugins for teaching.

The dots plugin is to get a set fo 100 images to do some simple programming tests on
The answer is a plugin to reveal hidden information in high bit depth images
widefield stack is a training dataset for the leidenuniv tracking plugin
interactive tutorial is to test your FIJI skills
the ROI interactive filter allows you to filter rois based on measured parameters, useful for teaching but potentially also for segmentation

All written by Joost Willemse
